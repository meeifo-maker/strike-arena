# CS2 Arena

Browser FPS inspired by Counter-Strike 2. Play 5v5 against bots with economy, buy menu, and rebindable controls.

## Run

```bash
npm install
npm run dev
```

## Defaults

| Action | Key |
|--------|-----|
| Move | WASD |
| Walk | Shift |
| Duck | Ctrl |
| Jump | Space |
| Fire | LMB |
| Reload | R |
| Buy menu | B |
| Pause / Controls | Esc |
| Weapons | 1 / 2 / 3 / scroll wheel |

Kills award weapon-based cash. Round wins pay `$3250`; losses pay a rising bonus (`$1400`–`$3400`).
